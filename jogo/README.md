# Jogo — O Interrogatório (Streamlit)

Cliente do jogo. As instruções completas de instalação e execução (API + jogo) estão no
[README da raiz](../README.md).

Resumo: suba antes a API de `../backend`, copie `.env.example` para `.env`, preencha
`IA_API_KEY` com a mesma `API_KEY` do backend e rode `streamlit run app.py`.
